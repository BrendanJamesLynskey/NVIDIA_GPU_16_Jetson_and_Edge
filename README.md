# Jetson — NVIDIA's Edge AI and Robotics Stack

The Jetson family from Orin Nano (7W) to AGX Orin (60W) and the Blackwell-based Jetson Thor — plus the software stack: JetPack, Linux for Tegra, Holoscan, Isaac, DeepStream — and worked examples of running modern LLMs at the edge. Includes an interactive edge use-case picker.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_16_Jetson_and_Edge/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
